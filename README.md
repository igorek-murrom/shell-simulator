# Shell Emulator

## Общее описание

Консольный эмулятор UNIX-подобной оболочки,
реализованный на Python без сторонних библиотек.

На первом этапе реализованы:

- интерактивный CLI;
- формирование приглашения на основе ОС;
- раскрытие переменных окружения;
- команды-заглушки `ls`, `cd`;
- команда `exit`;
- обработка неизвестных команд;
- обработка неверных аргументов.

## Запуск

Linux:

./run.sh
